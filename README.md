# Angelic Bakes

A responsive, self-contained bakery website. Open `index.html` in a browser; no installation or build step is required.

## Hosting

Deploy the repository root as a static website. For Cloudflare Pages, use no build command and set the output directory to `/`. For GitHub Pages, select the main branch and root folder in Settings → Pages.

## Before launch

- Replace the labelled illustrations with the sisters' real product photography.
- Confirm the product range, prices, delivery area and order terms.
- Add the business's real contact details and connect the enquiry form to a working inbox or form service.
- The current form creates a copyable enquiry draft only; it does not submit or store customer information.
- Remove the preview banner once the content and contact route are ready.

## Structure

All styling, illustrations and interaction code are contained in `index.html`. There are no external dependencies.
